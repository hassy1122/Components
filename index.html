Introduction

Plain HTML, CSS & JS

108 components covering everything a website needs — navigation, buttons, forms, cards, overlays, data display, e-commerce, loaders and more. Every component ships as one complete HTML document: hit Copy code, paste it into an .html file, open it in a browser. That's it. No frameworks, no dependencies, no build tooling.

Getting started

How to use

  1. Pick a component from the sidebar — every entry jumps straight to its live preview.
  2. Preview it live — each demo runs in an isolated frame, exactly like the code you copy.
  3. Hit “Copy code” — you get the full document: markup, styles and script in one block.
  4. Paste into a file — save as component.html and open it. Working component, zero setup.

Preview everything locally with npx serve . (or npm start), or open any component in a new tab with Open demo.
